### 1.2 主控板 — 反面布局（Bottom Layer / 底层铺铜与走线面）

> **设计原则**：主控板做到 **单面贴片（所有器件全在正面）**，大幅降低打样贴片费与手焊难度；**反面 90% 保留完整 `GND` 地平面**，仅走少量必要交叉信号线与散热过孔。

```text
   0         15        30        45        60        75 (mm)
55 ┌──────────────────────────────────────────────────┐
   │ (O)           ┌──────────────────────────┐  (O)  │ 51
   │  完整 GND 铺铜 │  ★ 天线净空区 (严禁铺铜!) ★ │       │
   │  (屏蔽干扰)    └──────────────────────────┘       │ 43
   │               ┌──────────────────────────┐       │
   │               │   ESP32 底部完整 GND 铜皮  │       │
   │               │   + 接地过孔阵列 (回流短)  │       │ 30
   │               └──────────────────────────┘       │
   │  ═══════ 少量短跳线通道 (GPIO16/17/18/25/26/27) ══│ 24
   │  ┌───────────┐                                   │
   │  │XL1509/LDO │  大面积 GND 铜皮 + 丝印标注端子线序: │
   │  │底部散热过孔│  J1: [+VIN] [GND]                 │ 14
   │  │阵列 (Ø0.3)│  J2~J4: [5V_H] [3V3] [DQ] [GND]   │
   │  └───────────┘                                   │
   │  (O)  [J1焊盘]   [J2焊盘]   [J3焊盘]   [J4焊盘] (O)
 0 └──────────────────────────────────────────────────┘
```

#### 反面核心设计要点
1. **天线净空区同步挖空**：反面 `(X:22~52, Y:43~55)` 与正面完全对齐挖空，绝不能铺地铜。
2. **散热过孔阵列**：在 `XL1509-5.0E1` 接地脚和 `AMS1117-3.3` TAB 散热焊盘下方打 **4~6 个 Ø0.3 mm 过孔**连到底层大面积 `GND` 铜皮，确保夏季铁皮屋 60℃ 环境下电源芯片温升极低。
3. **丝印防呆标注**：在底层端子焊盘旁用大号清晰丝印标明 `J1 (12-24V+, GND)` 以及 `J2/J3/J4 (H+, 3V3, DQ, GND)`，现场检修接线不易接错。
4. **功率走线宽度**：`VIN+` 和 `+5V_HEAT` 走线宽度 **≥ 0.8 mm（推荐 1.0 mm）**；`+3V3` 走线 **≥ 0.5 mm**；`DQ` 信号线 **0.25~0.3 mm**。

## 二、探头微型传感 PCB 布局（4.5 × 11.0 mm，插入 ID 6.0 mm 陶瓷帽）

> **板材规格**：宽 **4.5 mm** × 长 **11.0 mm** × 厚 **1.0 mm**（FR4，2 层板，喷锡或沉金）。
> 装入内径 6.0 mm 氧化铝陶瓷盲管后，四周间隙约 0.5~0.75 mm，全部以高导热硅胶满灌。

### 2.3 微型传感板 4 条黄金设计细节
1. **4 个接线焊盘“正面 2 个 + 反面 2 个”错开排布**：
   - 4.5 mm 宽度上如果并排放 4 个焊盘，每个焊盘宽不到 0.8 mm，手焊 26AWG 硅胶线极易连锡短路！
   - 改为 **正面放 `H+` / `3V3`，反面放 `DQ` / `GND`**，每个焊盘可以做到 **1.6 × 2.0 mm**，焊接极其牢固且绝不连锡！
2. **反“热短路”过孔摆法**：
   - 正反面中下段均大面积铺 `GND` 铜皮作为均温面，但连接正反面的过孔（Ø0.3 mm，左右各 2 个）**只打在 PCB 左右两侧边缘**，**绝不在 18B20 正下方直接打一排通孔连到加热电阻焊盘**。这样热量优先传导到紧邻的氧化铝陶瓷壁、再由外部流体决定散热快慢，空管/有液温差比值最高！
3. **18B20 引脚核对提醒**：
   - 画封装前务必核对所购型号（如 `GX18B20` vs `M1820`）的官方 Datasheet 确认 `SOT-23-3` 的 `VDD / DQ / GND` 引脚顺序（不同厂家的 SOT-23-3 脚位定义偶尔不同！）。
4. **拼板打样建议**：
   - 在立创 EDA 中将 `4.5 × 11.0 mm` 微型板做 **V-Cut 拼板**（例如 5×4 拼板 = 20 片，总尺寸约 35 × 55 mm），5 元特价打样一次就能拿到 100 片微型板，够做几十支探头！
