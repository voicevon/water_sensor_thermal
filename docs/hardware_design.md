## 1. 主控选型与完整引脚分配表

- 以下引脚已完全避开 ESP32 Strapping 启动引脚（`GPIO0 / GPIO2 / GPIO12 / GPIO15`）及内部 Flash 引脚（`GPIO6~11`）。

| ESP32-WROOM 引脚 | 网络标号 | 功能说明 | 外围电路要求 |

## 2. 分模块原理图设计详解

### 2.1 工业宽压电源模块（12V/24V → 5.0V → 3.3V）

```text
[12~24V 输入端子 J1]
   │
   ├─(VIN+)─► [F1: 1A/36V PTC] ─► [D1: SS34 防反接] ─┬─► [U1: XL1509-5.0E1] ─► [L1: 47µH/3A] ─┬─► +5V_HEAT (恒定5.0V)
   │                                                 │        │                   ▲           │
   │                                           [D2: SMBJ28A]  │             [D3: SS34]  [C3: 220µF/10V]
   │                                           [C1: 100µF/35V]│                   │           │
   └─(GND)───────────────────────────────────────────┴────────┴───────────────────┴───────────┴─► GND
                                                                                               │
                                 +5V_HEAT ─► [C4: 10µF] ─► [U2: AMS1117-3.3] ─► [C5: 100µF + 10µF + 100nF] ─► +3V3
```

- **恒定加热功率**：`XL1509-5.0E1`（40V 耐压，固定 5.0V 输出）确保无论现场供 12V 还是 24V，加热母线恒定为 **5.0V**（单路 34 Ω 加热功率严格锁定 **0.74 W / 147 mA**）。
- **宽温要求**：电解电容均选 **-40~105℃ 工业宽温低 ESR 型**，贴片电容全选 **X7R**，适配济南铁皮屋冬季 -10℃ 与夏季 +60℃。

### 2.2 单路高边 P-MOS 加热驱动电路（共 3 路相同，以 CH1 为例）

因为 18B20 需要公共 `GND`，将加热开关改在 **5V 高边**，探头内部加热电阻另一端直接接 `GND`，即可完美维持 **4 芯线缆**！

```text
                                      +5V_HEAT
                                         │
                                  ┌──────┴──────┐
                               [R_pu: 10kΩ]   Source
                                  │         [Q_p: AO3401A (P-MOS)]
                                  ├───────► Gate
                                  │            Drain
                              Collector          ├────► 端子 Pin1 (HEAT_5V_SW) ──► [探头 34Ω 加热] ──► GND
  ESP32 GPIO16 ─┬─► [R_b: 2.2kΩ] ─► Base [Q_n: S8050]  │
                │                  Emitter      [D4: SS14 续流保护]
           [R_pd: 10kΩ]              │                 │
                │                    ▼                 ▼
               GND                  GND               GND
```

- **工作原理与失效安全**：
  - `GPIO16 = LOW`（或上电复位/高阻态）：`R_pd (10kΩ)` 拉低，NPN `S8050` 截止，`R_pu (10kΩ)` 将 P-MOS `AO3401A` 栅极拉到 +5V（$V_{GS}=0\text{V}$），**加热强制断开**，绝不干烧！
  - `GPIO16 = HIGH (3.3V)`：`S8050` 饱和导通，将 `AO3401A` 栅极拉至 ~0.2V（$V_{GS} \approx -4.8\text{V}$），`AO3401A` 彻底导通（$R_{DS(on)} < 50\text{ m}\Omega$），稳定输出 5.0V 加热电流。

### 2.3 单路独立 18B20 数字测温接口（共 3 路相同，以 CH1 为例）

```text
+3V3 ──┬──► [R_lim_vdd: 10Ω / 磁珠] ──► 端子 Pin2 (VDD_3V3) ──► [探头 SOT-23-3 18B20 VDD + 100nF]
       │
   [R_ow: 4.7kΩ]
       │
       ├──► [R_ser: 100Ω] ──► ESP32 GPIO25 (DQ_CH1)
       │
       ├──► [ESD: PESD3V3L1BA] ──► GND
       │
       └──► 端子 Pin3 (DQ) ───────► [探头 SOT-23-3 18B20 DQ]

GND ──────────────────────────────► 端子 Pin4 (GND) ──────► [探头 18B20 GND & 加热电阻另一端]
```

- **为什么 3 路独立 GPIO 而不共用一根 1-Wire？**
  1. 现场更换任意一支损坏探头时**即插即用**，无需重新绑定 64 位 ROM 地址；
  2. 即使某一根管子探头进水短路把总线拉死，另外两根管子依然 100% 正常工作！
- **抗干扰**：`100Ω` 限流 + `PESD3V3` 静电保护 + `10Ω` 电源限流，防止 1.5 m 线缆引入浪涌或误短接损坏 ESP32 IO。
